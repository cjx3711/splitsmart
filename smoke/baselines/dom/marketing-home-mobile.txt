  - heading "What's in it" [level=2]
  - paragraph: The same jobs Splitwise does, minus the upsell that shows up while you're adding a taxi.
  - list:
    - listitem: Groups, friends, and one-off expenses that belong to neither
    - listitem: As many expenses a day as you want, because that's a strange thing to ration
    - listitem: "Six split types: equal, exact, percent, shares, adjustment, itemised"
    - listitem: Itemised bills, where each line has its own sharers and tax and tip get spread proportionally
    - listitem: Settle up, with suggested transfers if the group wants to simplify
    - listitem: 100+ currencies, each its own ledger. Nothing is converted, and JPY isn't treated as cents
    - listitem: A currency picker that puts the ones you actually use at the top
    - listitem: An activity feed for the groups and expenses you're on
    - listitem: Splitwise import, and your API key is used for the request and then dropped
    - listitem: Installable as a PWA, and the ledger stays on the device
    - listitem: A native JSON API, plus compatibility with the basic Splitwise API shapes
